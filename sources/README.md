# Archivierte Quelle: anime-offline-database (manami-project)

`anime-offline-database.json.zst` ist die letzte Fassung (Stand der Archivierung, Juli 2026) der
[anime-offline-database](https://github.com/manami-project/anime-offline-database) von manami-project,
veröffentlicht unter **ODbL 1.0 + DbCL 1.0** (Lizenztext: `LICENSE`, enthält beides).

Sie liegt hier, damit jederzeit nachvollziehbar ist, welche Daten daher stammen — das Projekt ist archiviert und
wird nicht mehr aktualisiert. Entpacken: `zstd -d anime-offline-database.json.zst`.
Aus ihr übernehmen wir nur nüchterne Metadaten (Titel, Typ, Folgenzahl, Status, Saison, Studios, Genres/Tags,
Synonyme, Querverweis-IDs) — keine Bilder, keine Beschreibungstexte, keine Bewertungen.
